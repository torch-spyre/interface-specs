# MemoryOrganization

Memory organization specification.

## Structure

```json
{
  "hbm": {
    "isPresent": 0 | 1
  },
  "lx": {
    "isPresent": 0 | 1
  }
}
```

## Fields

- **`hbm`**: HBM (High Bandwidth Memory) presence
  - `isPresent`: 0 (not present) or 1 (present)
- **`lx`**: LX (Local scratchpad) presence
  - `isPresent`: 0 (not present) or 1 (present)
