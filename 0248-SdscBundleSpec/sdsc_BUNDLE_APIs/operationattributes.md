# OperationAttributes

Operation attributes.

## Structure

```json
{
  "dataFormat_": "<string>",
  "fidelity_": "regular" | "high" | "low"
}
```

## Fields

- **`dataFormat_`**: (optional) Data format
- **`fidelity_`**: (optional) Computation fidelity
  - Enum: `["regular", "high", "low"]`
