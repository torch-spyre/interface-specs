# FoldProperty

Fold property with factor and label.

## Structure

```json
{
  "factor_": <int>,
  "label_": "<string>"
}
```

## Fields

- **`factor_`**: (required) Fold factor (integer >= 1)
- **`label_`**: (required) Fold label (e.g., "core", "corelet", "time")

## Example

```json
{
  "factor_": 2,
  "label_": "core"
}
```
