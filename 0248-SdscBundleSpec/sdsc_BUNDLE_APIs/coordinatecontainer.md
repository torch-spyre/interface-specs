# CoordinateContainer

Container for coordinate information.

## Structure

```json
{
  "coordInfo": <map<string, CoordinateInfo>>,
  "coreIdToWkSlice_": <object>
}
```

## Fields

- **`coordInfo`**: Map of dimension name to CoordinateInfo
  - Key Pattern: `^[a-z_][a-z0-9_]*$`
- **`coreIdToWkSlice_`**: Core ID to work slice mapping
